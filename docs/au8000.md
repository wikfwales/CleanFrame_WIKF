# Samsung AU8000 55-inch (2021) launcher

Fresh browser profiles start with YouTube, Amazon Prime Video, Samsung TV Plus,
WHIO-TV Dayton, Amazon Alexa, LookMovie2 and Stremio, in that order. Existing saved Home
orders are preserved; add Stremio through Settings → Apps on Home if preferences were already saved. Settings → Apps on Home adds, removes and reorders shortcuts;
OK picks up a row, Up/Down moves it, OK places it. Undo and cancellation remain.
Settings → Layout offers Dock, Grid and the original List. Grid uses three columns
and arrow-key navigation. Up from its first row reaches All apps and Settings.
The AU8000 is not a Frame, so Frame-only Art Mode is absent from Home controls.

The photo and pre-rendered glass dock are retained. Grid uses a static translucent
surface, not live backdrop blur. Focus animates only transform/background color;
reduced motion is respected. No network images, video backgrounds or runtime pixel
analysis were introduced. The manifest minimum is 6.0 for the 2021 Tizen generation;
this declares eligibility, not verified hardware compatibility. The existing package
identity remains a development reference: use an independently owned identity and
certificates in a separate installation task.

## Launch evidence and limits

| Shortcut | Mechanism | What is verified |
| --- | --- | --- |
| YouTube | Installed-app catalogue → `application.launch` | Existing reference ID `9Ur5IzDKqV.TizenYouTube`; runtime accepts that ID or exact YouTube name. Not verified on this AU8000. |
| Amazon Prime Video | Catalogue → `application.launch` | Reference ID `org.tizen.primevideo`; also matches exact Prime Video/Amazon Prime Video name. Not verified on this AU8000. |
| Samsung TV Plus | Catalogue → `application.launch` | Exact Samsung TV Plus/TV Plus name; no AU8000 ID invented. Requires the native app to be exposed by the catalogue. |
| WHIO-TV Dayton | Catalogue → `application.launch` | Exact WHIO/WHIO-TV/WHIO-TV Dayton/WHIO TV name. No confirmed Samsung TV app or universal ID; unavailable if absent. No unrelated news app is substituted. |
| Stremio | Catalogue → `application.launch` | Bundled Stremio icon; reference ID `IkWsFHtOY9.Stremio` or exact installed Stremio name. Not verified on this AU8000. [Official site](https://www.stremio.com/). |
| Amazon Alexa | Guidance only | No verified public direct-launch ID/API for the integrated assistant. Use a compatible remote microphone button with Alexa selected/configured in TV Voice Assistant settings, where supported. This tile does not launch an app. |
| LookMovie2 | `ApplicationControl(operation/view, 'https://www.lookmovie2.to/')` → `launchAppControl` with null app ID | Tizen documents VIEW + a website URL to launch a browser. Samsung AU8000 browser registration/policy and site playback remain unverified. Failure returns a readable error; no browser ID is guessed and no embedded player is used. |

Native resolution rejects missing or ambiguous matches. API callbacks/timeouts are
bounded. A successful callback confirms API acceptance, not a visible destination.
The browser preview reports device-only limitations rather than claiming TV success.

Tizen's official [Application Controls guide](https://docs.tizen.org/application/web/guides/app-management/app-controls/)
([source inspected](https://github.com/Samsung/Tizen-docs/blob/master/docs/application/web/guides/app-management/app-controls.md))
explicitly describes a website URL with VIEW for a browser. This verifies the generic
Tizen mechanism, not support by every Samsung firmware. The app already declares
`application.launch` and `application.info`. The repository's Samsung Application API
reference is in `docs/interaction-behaviour.md`; its live website was inaccessible
from this environment during research. No authoritative AU8000-specific Alexa launch
contract or WHIO app ID was established. Region/firmware and installed apps must be
confirmed by the owner in a later authorized device task.

## Browser development

Run `npm run dev:public` from the repository. Preview uses bundled public fonts,
remote-equivalent arrow keys, Enter and Escape. It never reaches the TV.
Run `npm run check`, `CLEANFRAME_PUBLIC_FONTS=1 npm run check:browser`,
`npm run check:public`, and `npm run export:public`. With the workspace-local browser
cache, prefix browser commands with `PLAYWRIGHT_BROWSERS_PATH="$PWD/.local/playwright"`.
The AU8000-specific regression suite is `node scripts/check-au8000.mjs` with that prefix.

The added Alexa outline is an original simplified identification symbol. TV Plus
uses an original TV/plus pictogram, WHIO an original Channel 7 pictogram, and LookMovie2
an original browser/player pictogram; these are not official service logos. YouTube
and Prime retain the bundled brand marks and their existing notices. Names alongside
the pictograms disambiguate the destinations. No third-party artwork was downloaded.
